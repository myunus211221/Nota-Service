# Nota Service (GitHub Pages)

Situs statis untuk halaman admin (`index.html`) dan halaman pelacakan konsumen (`tracking.html`).
Data tetap tersimpan di Google Spreadsheet lewat Apps Script (sebagai API).

Yang perlu diedit hanya `config.js` (isi `API_URL`). **Jangan** mengunggah `Code.gs` ke repository ini.
